# Question Paper Generator

A simple and professional web application to generate academic question papers.

## Features
- MCQ, Short & Long question sections
- Clean exam-style layout
- Live preview
- Print-ready format

## Technologies
- HTML
- CSS
- JavaScript

## Usage
Open `index.html` in your browser and fill in the form.

## Future Improvements
- Marks distribution
- Random question selection
- PDF export
- Teacher login system
